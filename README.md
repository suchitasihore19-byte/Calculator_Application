1. Introduction

The Smart Calculator is a Graphical User Interface (GUI) application developed using Java Swing. It is designed to perform basic mathematical calculations through an attractive and user-friendly interface.

The application provides different buttons for numbers and arithmetic operations. It displays the entered numbers, mathematical expressions, and final results.

2. Objectives

- To understand Java GUI programming.
- To implement Java Swing components.
- To understand event handling using ActionListener.
- To use layout managers for arranging components.
- To perform basic arithmetic operations.
- To develop a user-friendly calculator application.

3. Technologies Used

- Java: Programming language.
- Java Swing: Used to create the graphical interface.
- AWT: Used for graphics, fonts, colours and layouts.
- ActionListener: Used to handle button click events.
- EditPlus: Used to write and edit Java code.
- JDK: Used to compile and execute the program.

4. Features

1. Addition (+)
2. Subtraction (-)
3. Multiplication (*)
4. Division (/)
5. Percentage (%)
6. Positive and Negative (+/-)
7. Decimal Number Support
8. Clear All (AC)
9. Delete Last Digit (DEL)
10. Display of mathematical expressions and results.
11. Attractive dark-theme GUI with rounded buttons.

5. Java Components Used

Component| Purpose
JFrame| Creates the calculator window.
JPanel| Organizes the GUI components.
JLabel| Displays status and expressions.
JTextField| Displays numbers and results.
JButton| Creates calculator buttons.
GridLayout| Arranges buttons in rows and columns.
BorderLayout| Organizes the main interface.
ActionListener| Handles button click events.

7. How to Run the Project

Step 1: Install Java JDK on your computer.

Step 2: Open the Java file in EditPlus.

Step 3: Save the file as "SimpleCalculator.java".

Step 4: Open Command Prompt in the project folder.

Step 5: Compile the program:

javac SimpleCalculator.java

Step 6: Run the program:

java SimpleCalculator

Step 7: The Smart Calculator GUI window will appear.
